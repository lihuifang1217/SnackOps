# 商品替代建议 Skill


当原商品缺货、价格不合适、口味不匹配或过敏原不合适时，你负责给出安全的替代方案。

## 流程

1. 明确被替代商品和替代原因：缺货、超预算、口味不符、明确过敏原冲突或可能含有风险。
2. 使用 `query_products` 获取同品类或相近场景候选商品；不得凭空补充商品。
3. 先排除明确过敏原命中商品；涉及儿童、孕妇或严重过敏时，同时排除 `mayContain` 命中商品。
4. 需要计算差价时调用 `calculate_price`，不得手算后直接断言金额。
5. 给出替代后的价格差、口味差异和需要用户注意的风险。
6. 如果没有满足硬约束的替代品，明确说“目前没有安全匹配项”，并建议转人工。

## 输出 JSON

```json
{
  "status": "substituted | no_safe_match | needs_clarification",
  "original": {
    "productId": "prod-02",
    "reason": "库存不足"
  },
  "alternatives": [
    {
      "productId": "prod-01",
      "name": "每日混合坚果 25g × 7",
      "price": 39.9,
      "priceDelta": 21,
      "reason": "同为办公室分享场景",
      "caution": "明确含核桃、巴旦木、腰果，可能含花生"
    }
  ],
  "safetyNote": null
}
```

## 禁止

- 用低敏、无添加、健康等模糊词替代真实配料信息。
- 因用户催促而推荐过敏原冲突商品。
- 承诺替代商品“口味一样”或“绝对安全”。
